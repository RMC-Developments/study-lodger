# Study Planner

A simple study planner for tasks, projects, deadlines and focus sessions. Runs entirely in your browser — no account, no server. Your data is stored locally in your browser.

## Use it

Once deployed, open your GitHub Pages link:
`https://<your-username>.github.io/<repo-name>/`

On a phone or computer you can install it like an app (Share → Add to Home Screen on iOS, or the install icon in Chrome/Edge).

## Deploy on GitHub Pages

1. Create a new repository on GitHub (e.g. `study-planner`).
2. Upload all the files in this folder (keep the `icons` folder).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. After a minute or so your site is live at the link above.

## Backing up your data

Data is saved in your browser, so it doesn't sync between devices. Use **Export backup** in the sidebar to save a file, and **Import backup** to restore it on another device.
